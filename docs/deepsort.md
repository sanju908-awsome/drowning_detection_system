# DeepSORT

The video processor uses `deep-sort-realtime` and passes explicit YOLO detections as `([left, top, width, height], confidence, class_id)`. DeepSORT settings are configurable through `DEEPSORT_MAX_AGE`, `DEEPSORT_N_INIT`, and `DEEPSORT_MAX_COSINE_DISTANCE`. Track IDs index independent bounded histories. A history resets after more than one second without an observation to avoid carrying temporal evidence through long track gaps; histories are removed when a job ends and are never reattached across jobs. Short-gap identity switches are not detected, so the classifier still needs tracking-quality features and validation before operational use.

The selected Python package is `deep-sort-realtime==1.3.2`, a wrapper around DeepSORT. Its upstream repository declares the **MIT License**: [levan92/deep_sort_realtime](https://github.com/levan92/deep_sort_realtime). The default package embedder is PyTorch MobileNetV2 with bundled ImageNet-trained weights; no separate user-supplied ReID file is configured. The weight file's separate provenance/license was not independently confirmed, so review upstream notices before redistribution. The adapter passes detections using the documented `([left, top, width, height], confidence, class)` API. A synthetic moving-box test verified one ID across consecutive observations. It has not been evaluated on pool footage; identity switches, fragmentation, latency, and crowded/occluded performance are unmeasured. Do not infer that DeepSORT is accurate in swimming scenes.
